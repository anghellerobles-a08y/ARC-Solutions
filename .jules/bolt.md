## 2026-07-31 - Bundle Size & Render Optimization in Mora BMSC
**Learning:** Heavy visualization libraries like Recharts in Dashboard and complex UI components in sub-tabs drastically bloat initial entry chunk size, triggering Vite's 500 kB production build warnings. Utilizing React.lazy along with Suspense splits off these heavy components into separate, lazy-loaded JS chunks. This reduces the primary entry point load size by ~72% (from 538.42 kB to 151.87 kB) and improves page initialization time. Additionally, wrapping sub-page components with React.memo and memoizing calculations (e.g., reduce statistical operations) keeps toggle actions fast and free of unnecessary re-renders.
**Action:** Always identify if any route/tab uses substantial visualizers (like Recharts) or contains heavy computation. Code-split those tabs to lazy-load them on-demand, and memoize parent-rendered children to eliminate non-value-added component re-renders.
