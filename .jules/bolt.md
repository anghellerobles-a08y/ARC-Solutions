## 2025-05-18 - Code Splitting and Memoization for BMSC Mora
**Learning:** Recharts is a heavily interactive and feature-rich library, which when bundled in the main bundle increases chunk sizes significantly (~538 kB initial bundle size). Implementing code splitting and lazy loading on the main tabs (Dashboard, ClientesTable, Reportes) isolates these libraries and dependencies, reducing the initial JavaScript bundle size from 538.42 kB to 151.87 kB (~72% reduction). Furthermore, memoizing calculated reductions (totalMora, cases, statistics) and client searches in functional components with React.memo and useMemo avoids unnecessary processing overhead on frequent parent-level context or view changes.
**Action:** Use React.lazy and Suspense to separate component trees that rely on large visualization or interactive libraries into isolated chunks. Also, ensure React.memo is applied together with useMemo on functional components managing tabular and dashboard calculations.
